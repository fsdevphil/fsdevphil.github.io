how to use pi in python

instead of hardcoding 3.14 for pi, you can import math and use math.pi, which provides a much more precise floating-point representation of pi (3.141592653589793).

here is how you could write it:

import math

def area_of_circle(radius):
    area = math.pi * radius * radius
    return area

you can also import pi directly from the module:

from math import pi

def area_of_circle(radius):
    area = pi * radius * radius
    return area
