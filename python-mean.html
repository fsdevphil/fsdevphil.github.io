how to use mean in python 🐍

python's standard library includes the statistics module, which provides a dedicated mean() function.

here's how you could write it:

import statistics

numbers = [250, 241, 244, 255]

average = statistics.mean(numbers)
print(average)

you can also import mean directly from the module :

from statistics import mean

numbers = [250, 241, 244, 255]

average = mean(numbers)
print(average)
